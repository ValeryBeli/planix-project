# Planix

## О проекте

**Planix** — веб-приложение для тайм-менеджмента учебного процесса студентов, разработанное в рамках выпускной квалификационной работы.

Данный репозиторий является основным репозиторием проекта и содержит исходный код серверной и клиентской частей приложения.

Цель проекта — предоставить студентам единое пространство для управления расписанием занятий, учебными и личными задачами, а также формирования полезных привычек.

---

## Основные возможности

### Работа с расписанием

* просмотр учебного расписания;
* ручное добавление предметов;
* редактирование и удаление предметов;
* автоматический импорт расписания по ссылке с сайта КНИТУ.

### Работа с задачами

* создание задач;
* установка сроков выполнения;
* привязка задач к дисциплинам;
* изменение статуса задач;
* просмотр приближающихся дедлайнов;
* удаление и редактирование задач.

### Трекер привычек

* создание привычек;
* ежедневная отметка выполнения;
* хранение истории выполнения;
* визуализация прогресса;
* статистика по привычкам.

### Пользовательский профиль

* регистрация и авторизация;
* JWT-аутентификация;
* смена пароля;
* восстановление доступа через электронную почту;
* удаление учетной записи.

* AuthController
* UserController

Объекты передачи данных между клиентом и сервером.

JPA-сущности базы данных:

* User
* Subject
* Task

Слой доступа к данным.

Содержит бизнес-логику приложения:

* управление пользователями;
* работа с расписанием;
* управление задачами;

* парсинг расписания;

### security

Подсистема безопасности:

* JWT-аутентификация;
* фильтрация запросов;
* настройка Spring Security;
* получение текущего пользователя.

Глобальная обработка ошибок и пользовательские исключения.

# База данных

В проекте используется PostgreSQL.

Основные сущности:

* users — пользователи;
* subject — предметы расписания;
* task — задачи;
* habit — привычки;
* habit_log — отметки выполнения привычек.

Связи между сущностями реализованы средствами JPA/Hibernate.

# Импорт расписания

Одной из ключевых особенностей проекта является автоматический импорт расписания.

Алгоритм работы:

1. Пользователь вставляет ссылку на страницу расписания.
2. Сервер получает HTML-код страницы.
3. Модуль ParserService анализирует содержимое страницы.
4. Из HTML извлекаются данные о предметах.
5. Полученная информация преобразуется в объекты Subject.
6. Расписание сохраняется в базе данных.
7. Пользователь получает готовое расписание в приложении.

Для парсинга используется библиотека Jsoup.

# Запуск backend

## Требования

* Java 21
* Maven
* PostgreSQL

## Сборка проекта

```bash
mvn clean install
```

## Запуск приложения

```bash
mvn spring-boot:run
```

или

```bash
java -jar target/backend.jar
```

---

# Запуск frontend

## Требования

* Node.js
* npm

Установка зависимостей:

```bash
npm install
```

Запуск приложения:

```bash
npm run dev
```

Сборка production-версии:

```bash
npm run build
```
